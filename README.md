# AI Document Assistant

![Tests](https://github.com/dwaynekave12/ai-document-assistant/actions/workflows/tests.yml/badge.svg)

Upload a PDF and ask questions about it. Answers are grounded in the document,
with page references, using retrieval-augmented generation (RAG).

**Stack:** Python, FastAPI, PostgreSQL + pgvector, sentence-transformers,
Claude API, React (Vite), Docker, pytest, GitHub Actions.
